# Running for One Character

You can run this adventure for a single character of level 7. Ideally, that character should have proficiency in at least two of the following skills:

* Acrobatics
* Athletics
* Investigation
* Medicine
* Perception
* Religion

The solo character gains the [Blessing of the Lone Champion](rewards.html#blessing%20of%20the%20lone%20champion_drde) (see the introduction) to compensate for the lack of companions.
